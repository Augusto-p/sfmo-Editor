## 1. Описание Сервиса

**SFMO Editor** — это инструмент для редактирования, который работает полностью на стороне клиента (*client-side*) внутри веб-браузера пользователя. Сервис размещен с помощью GitHub Pages и предоставляет опциональную интеграцию со сторонними облачными хранилищами (Google Drive).

SFMO Editor **не обрабатывает, не хранит и не передает ваши файлы на собственные серверы**. Вся обработка данных происходит локально на вашем устройстве.
