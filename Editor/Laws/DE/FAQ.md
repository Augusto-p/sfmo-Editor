### 🔒 Datenschutz & Speicherung

**Wo werden meine Dateien gespeichert, wenn ich sie im SFMO Editor bearbeite?**

Ihre Dateien verbleiben an ihrem ursprünglichen Speicherort:

* **Lokale Dateien:** Verbleiben ausschließlich auf der Festplatte oder dem lokalen Speicher Ihres Geräts.
* **Google Drive-Dateien:** Werden direkt aus Ihrem persönlichen Google Drive-Konto gelesen und wieder dort gespeichert.
Unter keinen Umständen werden Ihre Dateien oder deren Inhalte auf Server von SFMO Editor hochgeladen.

**Sendet SFMO Editor meine Daten an einen eigenen Server?**

Nein. SFMO Editor ist eine 100 % *clientseitige* Webanwendung, die direkt in Ihrem Browser läuft. Wir besitzen, betreiben oder nutzen keine eigenen Server, um Ihre Dateien oder personenbezogenen Daten zu verarbeiten, zu speichern oder zu analysieren.

---

### ☁️ Google Drive-Integration

**Welche Berechtigungen oder Zugriffe fordert die App von meinem Google-Konto an?**

SFMO Editor fordert nur die Mindestberechtigungen an, die erforderlich sind, damit Sie die von Ihnen explizit ausgewählten Dateien auswählen, öffnen und speichern können. Wir greifen niemals auf den Rest Ihrer Drive-Daten zu und speichern weder Ihre Zugangsdaten noch Ihre Access Tokens.

**Kann ich SFMO Editor ohne eine Verbindung zu Google Drive nutzen?**

Ja! Die Google Drive-Integration ist völlig optional. Sie können den Editor nutzen, indem Sie Dateien direkt von Ihrem lokalen Computer laden und speichern, ohne sich bei Google anzumelden.

### 🌐 Hosting & Sicherheit

**Warum wird die Anwendung auf GitHub Pages gehostet?**

GitHub Pages ermöglicht es uns, den *Front-End*-Code der Weboberfläche schnell, sicher und transparent bereitzustellen. Wenn Sie auf die Website zugreifen, verarbeitet die Infrastruktur von GitHub standardmäßige HTTP-Anfragen (wie Ihre IP-Adresse), aber die von Ihnen bearbeiteten Inhalte werden niemals an deren Server gesendet oder dort gespeichert.

**Was passiert mit meinen Daten, wenn ich die Internetverbindung verliere?**

Wenn Sie mit lokalen Dateien arbeiten, erfolgt die gesamte Verarbeitung im Arbeitsspeicher Ihres Browsers, sodass Sie problemlos offline weiterarbeiten können. Eine Internetverbindung benötigen Sie nur, um Dateien über Google Drive zu öffnen oder zu synchronisieren.

### 🛠️ Support & Sicherheit

**Was soll ich tun, wenn ich einen Fehler oder ein technisches Problem finde?**

Sie können Fehler, technische Störungen melden oder neue Funktionen vorschlagen, indem Sie ein *Issue* auf unserem offiziellen GitHub-Repository erstellen.

**Ist SFMO Editor für vertrauliche oder sensiblen Dokumente sicher?**

Ja. Da Ihre Dateien niemals an Cloud-Server von SFMO Editor übertragen werden, ist das Risiko von Datenlecks in der Cloud ausgeschlossen. Die Sicherheit hängt ausschließlich vom Schutz Ihres eigenen lokalen Geräts und Ihres Google-Kontos ab.
