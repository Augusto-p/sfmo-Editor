### 🔒 Privacy e Archiviazione

**Dove vengono salvati i miei file quando li modifico in SFMO Editor?**

I tuoi file rimangono nella loro posizione di origine:

* **File locali:** Rimangono esclusivamente sul disco rigido o sulla memoria locale del tuo dispositivo.
* **File di Google Drive:** Vengono letti e salvati direttamente sul tuo account personale di Google Drive.
In nessuna circostanza i tuoi file o i loro contenuti vengono inviati ai server di SFMO Editor.

**SFMO Editor invia i miei dati a un server dedicato?**

No. SFMO Editor è un'applicazione web al 100% *client-side* che viene eseguita direttamente nel tuo browser. Non possediamo, gestiamo né utilizziamo server dedicati per elaborare, archiviare o analizzare i tuoi file o dati personali.

---

### ☁️ Integrazione con Google Drive

**Quali permessi o accessi richiede l'applicazione al mio account Google?**

SFMO Editor richiede solo i permessi minimi necessari per consentirti di scegliere, aprire e salvare i file specifici che selezioni esplicitamente. Non accediamo mai al resto dei tuoi dati su Drive, né memorizziamo le tue credenziali o i tuoi token di accesso.

**Posso usare SFMO Editor senza collegare Google Drive?**

Sì! L'integrazione con Google Drive è del tutto opzionale. Puoi utilizzare l'editor caricando e salvando i file direttamente sul tuo computer locale senza dover accedere a Google.

---

### 🌐 Hosting e Sicurezza

**Perché l'applicazione è ospitata su GitHub Pages?**

GitHub Pages ci consente di erogare il codice *front-end* dell'interfaccia web in modo rapido, sicuro e trasparente. Quando accedi al sito, l'infrastruttura di GitHub elabora le richieste HTTP standard (come il tuo indirizzo IP), ma il contenuto che modifichi non viene mai inviato né memorizzato sui loro server.

**Cosa succede ai miei dati se perdo la connessione a Internet?**

Se stai lavorando con file locali, tutta l'elaborazione avviene all'interno della memoria del tuo browser, consentendoti di continuare a modificare offline. Avrai bisogno di una connessione a Internet solo per aprire o sincronizzare i file tramite Google Drive.

### 🛠️ Supporto e Sicurezza

**Cosa devo fare se trovo un errore o un problema tecnico?**

Puoi segnalare bug, malfunzionamenti o suggerire nuove funzionalità aprendo una segnalazione (*Issue*) sul nostro repository ufficiale su GitHub.

**SFMO Editor è sicuro da usare per documenti confidenziali o sensibili?**

Sì. Poiché i tuoi file non vengono mai trasmessi a server cloud di terze parti appartenenti a SFMO Editor, il rischio di fughe di dati sul cloud viene eliminato. La sicurezza dipende interamente dalla protezione del tuo dispositivo locale e dal tuo account Google.
