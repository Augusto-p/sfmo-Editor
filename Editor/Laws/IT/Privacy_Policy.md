In **SFMO Editor**, apprezziamo e rispettiamo profondamente la tua privacy. Questa Informativa sulla Privacy spiega in modo trasparente come gestiamo le informazioni e conferma il nostro impegno nella protezione dei tuoi dati quando utilizzi la nostra applicazione.

---

## 1. Elaborazione 100% Locale (Client-Side) e Posizione dei File

**SFMO Editor** funziona in modo locale all'interno del tuo browser web (*client-side*). La gestione dei tuoi file dipende dalla loro origine:

* **File locali:** Se apri o modifichi un file memorizzato sul tuo dispositivo, questo rimane esclusivamente sul tuo dispositivo. L'elaborazione avviene nella memoria del tuo browser e il file non viene mai caricato o trasmesso a un server esterno.
* **File di Google Drive:** Se utilizzi l'integrazione per aprire un file salvato su Google Drive, il file rimane archiviato sul tuo account Google Drive. La lettura e il salvataggio dei dati avvengono direttamente tra il tuo browser e Google Drive; in nessun momento il file viene copiato, memorizzato o fatto transitare attraverso server di SFMO Editor.
* **Nessun server dedicato:** Non possediamo, affittiamo o gestiamo server per ospitare, elaborare, sincronizzare o effettuare copie di backup dei tuoi file o dati personali.
* **Nessun database centrale:** Non conserviamo registri di utilizzo (*log*), cronologia di navigazione o copie di backup dei tuoi documenti.

---

## 2. Raccolta dei Dati Personali

Poiché tutta la logica dell'applicazione viene eseguita localmente nel tuo browser:

* **Non raccogliamo Informazioni di Identificazione Personale (PII)** (come nomi, indirizzi e-mail o numeri di telefono) sui nostri sistemi.
* **Non tracciamo la tua attività** né creiamo profili utente.

---

## 3. Archiviazione Locale nel Browser

Per garantire il corretto funzionamento dello strumento e salvare le tue preferenze (come le configurazioni dell'interfaccia o i dati temporanei della sessione), **SFMO Editor** può utilizzare tecnologie di archiviazione locale del browser, quali:

* `LocalStorage` / `SessionStorage`
* `IndexedDB`

Tutte queste informazioni risiedono **esclusivamente sul tuo dispositivo** e puoi cancellarle in qualsiasi momento pulendo la cronologia e i dati di navigazione del tuo browser.

---

## 4. Servizi di Terze Parti e Integrazioni

Sebbene **SFMO Editor** non memorizzi dati su server propri, si avvale dei seguenti servizi di terze parti per l'hosting e l'integrazione opzionale:

* **Hosting su GitHub Pages:** L'applicazione viene erogata tramite l'infrastruttura di GitHub Pages (GitHub, Inc.). Quando accedi al sito, GitHub può raccogliere automaticamente informazioni tecniche standard dalle richieste HTTP (come il tuo indirizzo IP, il tipo di browser e l'orario di accesso) per fini di sicurezza, infrastruttura e diagnostica. Per maggiori dettagli, consulta l'[Informativa sulla Privacy di GitHub](https://www.google.com/search?q=https://docs.github.com/it/site-policy/privacy-policies/github-privacy-statement).
* **Integrazione con Google Drive (Opzionale):** Se scegli di aprire o salvare file direttamente dal tuo account Google Drive:
* L'autenticazione e il trasferimento dei file avvengono tramite le API ufficiali di Google direttamente tra il tuo browser e i server di Google.
* **SFMO Editor** richiede solo i permessi minimi necessari per leggere e scrivere i file specifici che selezioni esplicitamente.
* Non leggiamo, memorizziamo né trasmettiamo le tue credenziali, token di accesso o contenuti dei file a server esterni.
* L'utilizzo di questo servizio è soggetto all'[Informativa sulla Privacy di Google](https://policies.google.com/privacy?hl=it).



---

## 5. Sicurezza delle Informazioni

Poiché i tuoi file non vengono né trasmessi né elaborati su server esterni di proprietà di SFMO Editor, il rischio di fughe di dati sul cloud viene eliminato. La sicurezza dei tuoi dati dipende direttamente dalla protezione del tuo dispositivo e degli account di terze parti collegati (come il tuo account Google).
