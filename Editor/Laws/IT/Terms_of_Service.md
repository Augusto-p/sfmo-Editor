## 1. Descrizione del Servizio

**SFMO Editor** è uno strumento di modifica che funziona interamente lato client (*client-side*) all'interno del browser web dell'utente. Il Servizio è ospitato tramite GitHub Pages e offre l'integrazione opzionale con servizi di archiviazione cloud di terze parti (Google Drive).

SFMO Editor **non elabora, memorizza né trasmette i tuoi file a server dedicati**. Tutto l'trattamento dei dati avviene localmente sul tuo dispositivo.
