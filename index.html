SFMO Editor

A specialized editor for managing, structuring, and visualizing .sfmo data files

Application Purpose & Google Drive API Disclosure

SFMO Editor provides users with a specialized web tool integrated with Google Drive to open, edit, structure, and visualize custom .sfmo data files.

Google Drive Data Usage: SFMO Editor accesses your Google Drive files strictly to open, process, and save user-selected .sfmo data files. Our application does not store, harvest, or share your private Google Drive data on external servers. All operations are processed locally within your browser session.

What is SFMO Editor?

SFMO Editor is a web application featuring Google Drive integration that allows you to open, edit, and manage custom .sfmo files directly from your cloud storage. It enables you to build structured data tables connected to multiple datasets and generate synthesized analytical dashboards.

Key Features

Main Data Table

Supports Boolean, Text, and Number data types, along with direct references to stored datasets.

Multi-Dataset Support

Store and manage multiple independent datasets within the same file to reference in your main table.

Built-in Dashboards

Visualize synthesized metrics and data summaries generated directly from your main table.

Google Drive Integration

Seamlessly open and edit .sfmo files stored in your Google Drive storage.

How to Use the App

  1. Access the web app or install the integration via Google Workspace Marketplace.
  2. Right-click any .sfmo file inside Google Drive and select Open with > SFMO Editor.
  3. Edit your main table, link datasets, or analyze your data using the built-in dashboard.
